# Netmasha Attribution for Odoo 17

Odoo addon that links sales in your Odoo store to the Netmasha shoppers who sent them. It keeps Netmasha's click id on website orders and reports refunds and credit notes to Netmasha, signed with your webhook secret.

## Install

1. Copy `netmasha_attribution/` into your Odoo `addons_path` (or install it from Odoo Apps).
2. Restart Odoo, update the Apps list and install **Netmasha Attribution**.
3. Open Settings and enter your Netmasha store id and webhook secret (both from your Netmasha store portal).
