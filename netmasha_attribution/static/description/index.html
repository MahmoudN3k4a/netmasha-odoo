Netmasha Attribution

Connects this Odoo shop to your Netmasha account: it keeps the Netmasha click id of a shopper on the sale order, and reports paid orders, cancellations and refunds to Netmasha in real time, and turns the Netmasha points a shopper spends into a single-use discount code.

What it does

  • Keeps the attribution. A shopper who arrives from the Netmasha mall carries an opaque click id. The addon stores it on the sale order, so Netmasha knows which orders came from the mall.
  • Reports paid orders. When a customer invoice of such an order becomes paid, the addon sends a signed event to Netmasha.
  • Reports cancellations. When such an order is cancelled, the addon sends a signed cancellation event to Netmasha.
  • Reports refunds. When a credit note is posted for such an order, the addon sends a signed refund event to Netmasha.
  • Takes Netmasha points as a discount code. When a shopper spends Netmasha points at your shop, Netmasha asks the addon to create one single-use discount code with Odoo’s Loyalty module (a code starting with NM, a fixed amount, a minimum order and an expiry). The shopper enters it in the cart like any promotion code; the paid-order event names it, so the points are spent once. This is part of installing the addon, as agreed in your Netmasha merchant terms; there is no setting to switch it on or off. The request is signed with your webhook secret, must be less than five minutes old and can be used only once, and it can only create or remove the NM codes Netmasha made, never any other promotion.
  • Never blocks your shop. Every event is signed with a secret only your shop and Netmasha know. If a delivery fails, the addon writes a warning in the log and moves on; Netmasha's hourly readback reports anything that was missed.

Setup in 2 steps

Step-by-step help: business.netmasha.com/docs/connect-odoo (Odoo Online: connect Odoo Online).

  1. Install the module from Apps. The Netmasha website tracking code is part of the module.
  2. Open Settings → Netmasha, press Connect to Netmasha, sign in to Netmasha and approve. You are back in Odoo, connected. Nothing to copy or paste: no store id, no secret, no API key.

To stop, press Disconnect in the same place.

What leaves this shop

Only the following is sent to Netmasha, and only for orders that carry a Netmasha click id or were paid with a Netmasha discount code:

  • When you press Connect, the shop address and a one-time check value go to the Netmasha portal, and Netmasha sends back your store id and a secret in exchange for a one-time code. After that, Netmasha reads your orders, credit notes and products through this module's own signed routes, so it does not hold an Odoo API key.
  • For a paid order: the sale order id and name, the total and the tax amount, the currency, the number of order lines, the order date and the opaque click id, and the code and discount amount of the Netmasha discount code used (none of your other promotions).
  • For a cancelled order: the sale order id, the currency and the time of the cancellation.
  • For a credit note: the credit note id, the id of the sale order it belongs to, the amount, the currency and the invoice date.

Privacy

The addon stores one thing on your side: the opaque Netmasha click id on the sale order. It is a random reference, not a customer record. No customer name, address, e-mail or payment detail is stored by the addon and no customer data leaves your Odoo server: the order totals listed above are the only information that is sent to Netmasha. What Netmasha sends in is a code, an amount, a minimum order and an expiry; it contains no personal data.

Requirements

  • Odoo 17.0 with the Sales, Invoicing, Website and Loyalty (sale_loyalty) modules; Loyalty is installed with the addon.
  • A Netmasha account and a webhook secret from your Netmasha store page.
